# 示例 · 智枢智能

## 一句话判断
企业 Agent 平台里少见的不靠「模型更强」讲故事的团队——核心是把权限、审计与流程编排做成可交付的产品；已投，后续跟踪续费与私有化交付毛利率。

## 判断依据
- **产品**：面向中大型企业的 Agent 工作流平台，卖点是工具接入、权限边界、审计留痕；底层模型可替换，包括国产模型。
- **客户**：金融与制造企业的信息化部门，采购流程长但续费相对稳定；投后关键看试点能否转为生产。
- **竞争**：通用大模型厂商向下做平台，RPA 与低代码厂商向上加 Agent；差异化在权限与审计的深度。
- **团队**：产品与销售来自企业软件，交付由合作集成商分担——这是毛利能否改善的关键。
- **估值**：按「企业软件 + 平台」区间进入，容忍 18 个月不盈利，但要求 NDR 与毛利改善。

## 关键假设
- [ ] 2027 年内 NDR 不低于 110%（示例性目标）
- [ ] 私有化交付毛利率提升到 55% 以上
- [ ] 至少 3 个客户从试点转为全公司采购
- [x] 核心产品团队在 A 轮后 12 个月保持稳定

## 风险与反证
- 通用模型厂商把「Agent 编排」做成免费功能，平台价值被压向交付服务。
- 私有化部署拖累毛利，规模不经济；大客户定制需求还会导致版本分裂。
- 反证信号：续费率下滑、实施周期拉长、合作集成商流失。
- 文中的 NDR、毛利率等数字为示例性假设，不是真实经营数据。

## 证据与时间线
- 2025-11-18 · 首次尽调（示例），确认产品可替换底层模型，权限与审计是核心差异
- 2026-04-22 · 投后第一次季度沟通：试点客户 6 家，转生产 2 家
- 2026-10-09 · Q3 复盘：NDR 接近目标下沿，私有化毛利率仍偏低
